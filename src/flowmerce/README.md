# Flowmerce portfolio screenshots

The featured project and case study use an existing repository preview as a fallback.

To show the **current screenshots** that were supplied separately, add these image files into this folder:

- `dashboard.webp` (featured project cover and case study hero)
- `inventory.webp`
- `finance.webp`
- `pos.webp`
- `ai-assistant.webp`
- `tables-qr.webp`
- `landing.webp` (optional, provided as an extra screenshot)

The page will automatically replace the preview with `dashboard.webp` and reveal the screenshot gallery as the other files are uploaded. Missing images remain hidden, so no broken thumbnails appear.

Use screenshots containing fictitious sample business data. Do not include passwords, secret keys, real customer data, or unpublished internal information.

**No Laravel deployment is needed**: this portfolio is served as a static GitHub Pages website.
