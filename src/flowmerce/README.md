# Flowmerce portfolio screenshots

The portfolio is prepared to display seven screenshots from the Flowmerce project. Use the files from `Flowmerce_Portfolio_Screenshots.zip` and upload the seven `.webp` files **directly into `src/flowmerce/`** in the `Maximust27/Maximust27.github.io` repository.

## Files and placement

| Image | Used in |
| --- | --- |
| `landing.webp` | **Homepage Featured Project cover** and case study hero (replaces the previous Flowmerce screenshot) |
| `dashboard.webp` | Case study gallery: dashboard |
| `inventory.webp` | Case study gallery: inventory |
| `finance.webp` | Case study gallery: financial overview |
| `pos.webp` | Case study gallery: point-of-sale |
| `ai-assistant.webp` | Case study gallery: AI assistant |
| `tables-qr.webp` | Case study gallery: tables & QR |

The two pages automatically reveal the original screenshot images once those files exist. Until then, they show an intentional branded placeholder instead of the old screenshot or a broken image icon. Other missing gallery images remain hidden.

## GitHub web upload (no terminal needed)

1. Open [this folder](https://github.com/Maximust27/Maximust27.github.io/tree/main/src/flowmerce).
2. Click **Add file → Upload files**.
3. Drag in all seven `.webp` files extracted from `Flowmerce_Portfolio_Screenshots.zip`. Upload the image files themselves, not the ZIP and not the nested folder.
4. Commit directly to `main`. The GitHub Pages website will pick up the changes when its deployment completes.

Pages:
- Homepage: https://maximust27.github.io/
- Case study: https://maximust27.github.io/flowmerce.html

Only publish screenshots containing fictional demo data. Remove any passwords, credentials, or private business information before uploading.

**No Laravel deployment is needed:** the portfolio itself is a static GitHub Pages site.
